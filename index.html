        SYSTEM

        三部分组成，可单独选，也可整套交付

        硬件负责看清楚，软件负责认出来，ERP 负责管起来。每部分都可以按你的门幅、布种和管理流程配置。

        01

        视觉硬件

        线阵相机、线扫光源、计米编码器和安装支架，按门幅和精度配齐。

        • 4K / 8K / 16K 线阵相机，灰度或彩色
        • 900mm 段长线扫 LED 光源，可拼接，角度可调
        • 计米轮编码器，行触发与布速同步
        • 4080 型材支架，可直接加装到现有验布机
        相机数量、光源长度可在线选配
        02

        桌面检测软件

        装在验布机旁的工控机上，现场工人开卷即用，工程师在同一台机器上调试。

        • 检测端：实时瀑布流、瑕疵框选、报警与回退
        • 标注端：整卷标注、样本墙、标注规范
        • 训练端：一键生成训练集，按布种训练模型
        • 相机调试、电机调速、日志诊断内置
        Windows 工控机 · 本地运行，不依赖外网
        03

        ERP 质检系统

        把每一卷布的检测结果变成可查询、可追溯、可对账的质检数据。

        • 布卷档案：卷号、米数、瑕疵坐标、原图截图
        • 四分制自动评分，出具质检报告
        • 班次 / 机台 / 布种 / 客户多维报表
        • 对接现有 ERP / MES，或按需定制开发

        ERP · 质检管理

        每一卷布都有一份可追溯的质检档案

        检测数据自动写入质检系统，可以接你现有的 ERP，也可以按你的业务流程定制。

        • 档

          布卷档案

          卷号、布种、米数、每处瑕疵的纵向米数和横向位置，都附原图截图。

        • 分

          四分制自动评分

          按瑕疵尺寸自动扣分，换算成每百平方码得分并判定等级，标准也可以自定义。

        • 表

          多维报表

          按班次、机台、布种、织机、客户统计瑕疵率，帮你找到问题源头。

        • 接

          系统对接与定制

          提供 API、数据库中间表和 Excel 导出，订单、出库、客户投诉流程都可以按需开发。

        技术参数

        相机工业线阵相机，4K 灰度 / 4K 三线彩色 / 8K / 16K 可选，GigE 或 CoaXPress 接口
