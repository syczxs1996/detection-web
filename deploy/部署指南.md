# 织鉴官网部署指南（第一版：宣传页 + 选配页）

目标：买一台香港服务器，用 IP 地址把网站跑起来，完整走一遍「买服务器 → 安全初始化 → 发布 → 更新 → 回滚」。
域名和 HTTPS 放在后面，等文案定稿再做；流程和正式上线完全一样。

**为什么选香港**：不用备案，买完当天就能上线；国外客户访问快，国内访问也够用；以后买了域名可以直接绑。
以后如果换国内服务器，只需要多一个「ICP 备案」步骤，其余全部照搬。

---

## 0. 本机准备（5 分钟）

本机需要 **Node.js**（已装）和 **OpenSSH**（Windows 10/11 自带）。打开 PowerShell，生成一对登录密钥：

```powershell
ssh-keygen -t ed25519 -C "zhijian-deploy"
# 一路回车即可。会生成两个文件：
#   C:\Users\你的用户名\.ssh\id_ed25519      ← 私钥，永远不要发给任何人
#   C:\Users\你的用户名\.ssh\id_ed25519.pub  ← 公钥，等下要交给服务器
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub   # 显示公钥内容，复制备用
```

> 密钥登录比密码安全得多：服务器上可以彻底关掉密码登录，暴力猜密码的机器人就没机会了。

## 1. 买服务器（15 分钟）

阿里云或腾讯云都可以，选 **轻量应用服务器**：

| 项目 | 选什么 |
|---|---|
| 地域 | **中国香港** |
| 镜像 | **Ubuntu 24.04 LTS**（或 22.04） |
| 套餐 | 最低一档就够（1～2 核、1～2 GB 内存）。网站只有 4 MB，静态页面几乎不占资源 |
| 时长 | 练手先买 1 个月；确定要用再续费 |
| 登录方式 | 如果有「密钥」选项，把第 0 步的公钥粘进去；没有的话先设一个强密码 |

买完在控制台记下 **公网 IP**，下文用 `1.2.3.4` 代替。

**防火墙（控制台里的「防火墙 / 安全组」）**：确认放行 **22（SSH）、80（HTTP）、443（HTTPS）** 三个端口。
云厂商的防火墙和服务器自己的防火墙是两道门，**两道都要开**。

## 2. 首次登录与初始化（20 分钟）

### 2.1 登录

```powershell
ssh root@1.2.3.4        # 阿里云通常是 root
ssh ubuntu@1.2.3.4      # 腾讯云 Ubuntu 镜像通常是 ubuntu
```

第一次会问 `Are you sure you want to continue connecting?`，输入 `yes`。这是在记录服务器的「指纹」，以后如果指纹变了说明可能被冒充，ssh 会报警。

### 2.2 上传并运行初始化脚本

另开一个 PowerShell 窗口（在本机）：

```powershell
cd D:\work\web
scp deploy\setup-server.sh root@1.2.3.4:/tmp/      # 用户名按上一步换
```

回到服务器窗口：

```bash
sudo bash /tmp/setup-server.sh
```

脚本会做 6 件事，每一步都会打印出来：更新系统 → 装 nginx、防火墙、自动安全更新 → 建 `deploy` 用户 → 建网站目录 → 配好 nginx → 开防火墙。
最后浏览器打开 `http://1.2.3.4`，看到 **「服务器已就绪」** 就成功了。

### 2.3 （仅密码登录时需要）把公钥交给 deploy 用户

如果第 1 步没有用密钥、脚本提示「没找到 authorized_keys」，在服务器上执行（把引号里换成你的公钥整行）：

```bash
sudo -u deploy bash -c 'echo "ssh-ed25519 AAAA...你的公钥... zhijian-deploy" >> ~/.ssh/authorized_keys'
```

### 2.4 确认 deploy 能免密登录

在**本机新开**一个窗口：

```powershell
ssh deploy@1.2.3.4
```

不用输密码就进去了，说明配好了。

### 2.5 关掉密码登录（推荐）

**先确认 2.4 成功**，并且保留一个已登录的窗口不要关（万一改错还能救回来）。在服务器上：

```bash
sudo sed -i 's/^#\?PasswordAuthentication .*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo sshd -t && sudo systemctl restart ssh
```

再开一个新窗口 `ssh deploy@1.2.3.4` 确认还能登录，然后才关旧窗口。

## 3. 第一次发布（2 分钟）

本机 PowerShell：

```powershell
cd D:\work\web
powershell -ExecutionPolicy Bypass -File deploy\deploy.ps1 -Server 1.2.3.4
```

它会：本地打包 `dist/` → 压缩上传 → 解压到服务器 `releases/时间戳/` → 把 `current` 指过去。
浏览器打开 `http://1.2.3.4`，就是你的网站了。把这个地址发给同事、在厂里的电视上打开都可以。

## 4. 日常：改文案 → 再发布 / 出问题 → 回滚

```powershell
# 改完页面后，重新发布（就是第 3 步那条命令）
powershell -ExecutionPolicy Bypass -File deploy\deploy.ps1 -Server 1.2.3.4

# 看服务器上有哪些版本（* 是当前）
powershell -ExecutionPolicy Bypass -File deploy\deploy.ps1 -Server 1.2.3.4 -List

# 新版有问题，退回上一个版本（几秒钟生效，不用重新上传）
powershell -ExecutionPolicy Bypass -File deploy\deploy.ps1 -Server 1.2.3.4 -Rollback
```

服务器自动保留最近 5 个版本。发布和回滚都是「切换指针」，访客不会看到改到一半的页面。

## 5. 可选：文案定稿前加访问密码

不想让陌生人通过 IP 看到未定稿的内容，可以加一道浏览器密码框。在服务器上：

```bash
sudo apt-get install -y apache2-utils
sudo htpasswd -c /etc/nginx/.htpasswd zhijian       # 用户名 zhijian，按提示设密码
sudo sed -i 's/# auth_basic/auth_basic/' /etc/nginx/sites-available/zhijian
sudo nginx -t && sudo systemctl reload nginx
```

要撤掉：把那两行改回 `# auth_basic`，再 reload。

## 6. 以后：域名 + HTTPS（文案定稿后）

1. **买域名**：`.com` 最适合面向国外客户。在云厂商买完做实名认证（1～3 天）。
2. **解析**：在域名控制台加一条 **A 记录**，`@` 和 `www` 都指向 `1.2.3.4`。
3. **装免费证书**（Let's Encrypt，自动续期）：
   ```bash
   sudo sed -i 's/server_name _;/server_name example.com www.example.com;/' /etc/nginx/sites-available/zhijian
   sudo nginx -t && sudo systemctl reload nginx
   sudo apt-get install -y certbot python3-certbot-nginx
   sudo certbot --nginx -d example.com -d www.example.com     # 按提示填邮箱、同意条款、选自动跳转 https
   sudo certbot renew --dry-run                                 # 测试自动续期
   ```
4. 之后发布命令里的 `-Server` 也可以直接写域名。

> 香港服务器绑域名**不需要备案**。如果以后为了国内访问速度换到国内服务器，那时再做 ICP 备案（1～3 周），
> 并在页脚加备案号链接到 https://beian.miit.gov.cn 。

## 排错

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| `ssh` 一直卡住、超时 | 云控制台防火墙没开 22 | 控制台 → 防火墙 → 放行 22 |
| 网页打不开，但 ssh 能连 | 控制台没开 80 | 放行 80（和 443） |
| 打开是 nginx 欢迎页 | 默认站点没删 | 重新跑一次 `sudo bash /tmp/setup-server.sh` |
| `Permission denied (publickey)` | 公钥没加到 deploy | 做第 2.3 步 |
| `WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED` | 服务器重装过 | 确认是你重装的，再运行 `ssh-keygen -R 1.2.3.4` |
| 发布成功但页面没变 | 浏览器缓存 | Ctrl+F5 |
| 页面显示「没有这个页面」/ 404 | 地址写错 | 首页 `/`，选配页 `/configurator.html` |

服务器上看日志：

```bash
sudo tail -n 50 /var/log/nginx/error.log     # nginx 报错
sudo tail -f /var/log/nginx/access.log       # 实时看谁在访问
```

| `build.js` | 本机 | 打包 `dist/`（只含本版要上线的页面） |
